## Things I've built

- **[Tollgate](https://github.com/KartikManral092006/TollGate):** team approvals for AI coding agents. Your coding agent moves fast; production waits for your team. [Try it](https://toll-gate-mo7d.vercel.app)
- **[Lien](https://github.com/KartikManral092006/Lien):** cross-chain lending, with collateral on Base, credit on Unichain and one ledger on Reactive Network. [Dashboard](https://kartikmanral092006.github.io/Lien/)
- **Flux:** an AI vendor-risk platform that spots failing suppliers before the scorecard does.
- **[Planner](https://trip-planner-orcin-two.vercel.app):** a multi-agent trip planner. Agents do the research, code does the maths, and you approve. It's my re-architecture of an open-source LangGraph planner.
